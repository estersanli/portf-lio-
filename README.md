# Portfólio — Ester Lima

## Sobre o Projeto

Este projeto consiste no desenvolvimento do meu portfólio profissional, criado com o objetivo de apresentar minha trajetória na área de tecnologia, minhas habilidades, experiências e projetos desenvolvidos.

O portfólio foi pensado para apresentar minhas informações de forma visual, organizada e profissional, permitindo que recrutadores, empresas e outros profissionais possam conhecer meu perfil e entrar em contato comigo.

Atualmente, sou graduanda em Análise e Desenvolvimento de Sistemas e técnica em Informática pelo IFMA, com interesse no desenvolvimento de soluções digitais e na área de desenvolvimento Front-End.
