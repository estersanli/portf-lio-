# 💻 Portfólio — Ester Lima

## Sobre o Projeto

Este projeto consiste no desenvolvimento do meu portfólio profissional, criado com o objetivo de apresentar minha trajetória na área de tecnologia, minhas habilidades, experiências e projetos desenvolvidos.

O portfólio foi pensado para apresentar minhas informações de forma visual, organizada e profissional, permitindo que recrutadores, empresas e outros profissionais possam conhecer meu perfil e entrar em contato comigo.

Atualmente, sou graduanda em Análise e Desenvolvimento de Sistemas e técnica em Informática pelo IFMA, com interesse no desenvolvimento de soluções digitais e na área de desenvolvimento Front-End.

## 💡 Ideação

A ideia do projeto surgiu da necessidade de criar um espaço profissional para apresentar minha trajetória, habilidades e projetos na área de tecnologia.

O desenvolvimento foi pensado para proporcionar uma experiência simples e intuitiva, utilizando uma identidade visual moderna e elementos que destacam as informações mais importantes do meu perfil.

---

## 📝 Esqueleto do Protótipo

Antes do desenvolvimento da interface final, foi estruturada a organização das principais seções do portfólio, definindo a disposição das informações e a navegação entre os conteúdos.

As principais seções planejadas foram:

- Início
- Sobre Mim
- Habilidades
- Projetos
- Contato
